# Para Code 更新履歴

Para Code が本家 VS Code に加えた変更の一覧です。新しいバージョンが上に来ます。

## 未リリース

### 新機能

- タブを選んでいるときにタブの上端に出る色帯が、いま開いているスペースの色になりました。暗くて背景に沈む色は自動で明るさを調整します。色を設定していないスペースではこれまでどおりの見え方です

## paracode-139（2026-08-30）

### 改善

- ターミナルのタブバーに出るコマンドプリセットのフォルダボタンで、フォルダ名も一緒に表示できるようにしました。フォルダのボタンを右クリックして「フォルダ名も表示する」を選ぶと切り替わります。フォルダごとに選べるので、名前が長いものはアイコンだけのままにしておけます

### 修正

- 更新のあと、常駐が抱えていたターミナルに繋ぎ直せず、代わりに新しいシェルが開いていたのを直しました。走っていたプロセスはそのまま残っているのに、どのタブからも見えない状態になり、更新のたびにターミナルの本数だけが増えていました。エディタのタブとして開いていたターミナルで起きていました
- 常駐が抱えているターミナルの一覧で、まだ開いていないものが名前もプロセス番号も空のまま並び、どれがどれか見分けられなかったのを直しました
- 更新のあと、パネルのターミナルの並びが失われることがあったのを直しました。並びが一度消えると次に起動しても戻らず、走っているプロセスが画面に出てくる道が無くなっていました
- 繋ぎ直しに失敗して開いた空のターミナルが残っていると、次の更新でそちらに繋がってしまい、仕事が入っている元のターミナルが取り残されることがあったのを直しました
- ターミナルの状態がうまく読めなかったとき、無関係な別のターミナルに繋がってしまうことがあったのを直しました。読めなかったときは新しいターミナルを開くようにしています
- 更新のあと、引き取ったターミナルが別のスペースに紛れ込むことがあったのを直しました。スペースが分かっているものは元のスペースへ戻ります（作業フォルダから所属を推測していたターミナルは、引き続き所属不明になることがあります）
- SSH 接続先でターミナルを復元するとき、無関係な別のターミナルに繋がってしまうことがあったのを直しました
- Markdown や HTML のプレビュー表示で、検索欄に文字を入れても何も見つからなかったのを直しました。拡張機能の説明ページなど、ほかのプレビュー画面でも検索できるようになっています
- Word・Excel の表示と比較が「読み込み中…」のまま何も出てこなくなることがあったのを直しました。これまでは待ち続けるしかありませんでしたが、返ってこないと分かった時点で自動的に開き直し、それでも駄目なら理由と一緒に **再試行** と **既定のアプリで開く** のボタンが出ます。Word の比較では、開いたのに中身が空だったことを検知できておらず、この開き直しが一度も働いていませんでした

## paracode-138（2026-08-29）

- 内蔵ブラウザに **名前付きプロファイル** が追加されました。「PRD」「TEST」のように環境ごとに名前を付けておくと、一度ログインすれば次回から自動でログイン状態が復元されます。アドレスバー右のピルから切り替え・作成・管理ができ、エージェントからも名前を指定して開けます

## paracode-137（2026-08-29）

### 新機能

- Excel の**表示形式**が反映されるようになりました。パーセント・通貨・桁区切り・会計書式・指数表記・分数・経過時間・「〇〇円」のような単位付きの書式が、Excel と同じ文字列で表示されます
- Excel の**テーブル**を、見出し行・集計行・1行おきの網掛け・強調列として表示するようになりました。フィルタが設定されている見出しには印が付きます
- Word の**グラフ**と **SmartArt** が表示されるようになりました。これまでは空白になっていた箇所に、棒グラフや図表の中身が描かれます
- Word の**テキストボックス**と**図形**の中身が表示されるようになりました

### 修正

- 日付や時刻のセルが、書式を無視した内部形式のまま表示されることがあったのを直しました
- 会計書式のセルに、通貨記号や桁区切りが付かなかったのを直しました
- Excel のテーブルで、見出し行が見出しとして扱われず、網掛けが1行ずれていたのを直しました
- フィルタの印が、関係のない行にも出ることがあったのを直しました
- ウィンドウ位置の情報によっては、ブックの詳細な解析が丸ごと失敗していたのを直しました
- 大きなブックを開くと、途中から表示形式が外れて数値がそのまま出ることがあったのを直しました

## paracode-125（2026-08-25）

### 新機能

- エディタタブを選んだときに出る枠の色が、いま開いているスペースの色になりました。暗くて背景に沈む色は自動で明るさを調整するので、どのスペースでも枠が見えます。色を設定していないスペースではこれまでどおりの見え方です
- 「更新をまたいで繋ぎ直す」を、設定画面から SSH 接続先ごとに切り替えられるようになりました（リモート設定に保存されます）。これまでは接続先の設定ファイルを手で開く以外に有効にする方法がありませんでした

### 改善

- 大きなモニタで、ダイアログが画面の高さに合わせて縦に伸びるようになりました。設定・通知設定・コマンドプリセット・更新履歴は、これまで高さが固定だったので一度に読める行数が変わりませんでした
- 使用量ダッシュボードとセッション履歴は、広い画面では横にも広がるようになりました。グラフに入る日数が増え、セッション履歴では一覧の書き出しが長く読めます
- 「設定 (Para Code)」から内部の設定キー（`paradis.` で始まる文字列）の表示をやめ、各項目の説明を短く書き直しました。行が名前だけになって読みやすくなります。キーで検索することは今までどおりできます
- 「ウィンドウを閉じるときの動き」「エージェント実行中のスリープ」の選択肢に、`ask` や `off` といった内部の値がそのまま出ていたのをやめました
- 「新しいスペース」の作成ダイアログの見た目を、設定や通知設定と同じ形に揃えました。上に見出しの帯、下にボタンの帯が付き、入力欄・ボタン・角の丸みが他のダイアログと同じになります。指示が一番上・エージェントはアイコンで選ぶ、という並び自体はこれまでどおりです
- 常駐ターミナルの詳細と確認ダイアログに、**どのマシンの常駐なのか**が出るようになりました。接続先の常駐を止めるときは、同じ接続先に繋いでいる他のウィンドウのターミナルも一緒に終わることを、押す前にお知らせします
- 「設定 (Para Code)」ダイアログに、これまで出ていなかった設定を追加しました。レイアウトプリセットの管理、SSH 接続まわりの挙動、AI 利用量リミット・GitHub API・モバイル連携の細かい調整項目などが対象です

### 修正

- Workspaces のスペース行で、プルリクエスト・Issue 件数・未コミットの差分・メモの未完了件数の段が出ていなかったのを直しました。リポジトリを折りたたんだときのピン留めした行にだけ出て、それ以外の行では設定でチェックを入れていても表示されない状態になっていました
- エディタを何度も分割して1つ1つが低くなったとき、空のエディタに出るロゴがはみ出して見切れていたのを直しました。高さが足りないときはロゴを隠し、代わりにショートカットの一覧を表示します
- 使用量ダッシュボードの段組みが、ウィンドウの幅ではなくダイアログ自身の幅で切り替わるようになりました。ダイアログの中身が狭いのに段組みが畳まれない、という食い違いがなくなります
- ステータスバーから開くポップオーバー（各種サービスの状態、利用量、ポート一覧、リソース、常駐ターミナル、表示と並び）を開いたときに、枠全体が青くふちどられていたのを直しました
- SSH 接続中のウィンドウで、常駐ターミナルの表示が**接続先のもの**になりました。これまでは接続先のウィンドウにも手元の PC の常駐の本数が出ていて、そこから「停止」を押すと、目の前のターミナルではなく手元の PC のターミナルが終了していました。本数・稼働時間・停止・再起動のすべてが、いま見ているマシンのものに揃います
- Modern UI（設定 → `workbench.experimental.modernUI`、既定で有効）を使っていると、Workspaces・Para ホスト・ウィンドウの半透明化まわりの一部の見た目が崩れていた不具合を直しました。ワークスペース一覧・Para ホスト一覧の左端の色付き縦線が行ごとに途切れて見えていた問題、半透明ウィンドウで左右のサイドバーや下部パネル（ターミナルを含む）の中身が不透明に塗りつぶされていた問題が対象です
- タイトルバーのポート一覧アイコンが、環境によっては他のウィジェットから離れて中途半端な位置に単独で表示されることがあった不具合を直しました。CPU/RAM モニターなどと同じ左側にまとまって表示されます

## paracode-124（2026-08-24）

### 修正

- Excel・Word の新しい意味解析ビューアは、まだ実験的な経路として明示的に選んだ場合だけ使われます。通常は従来の読み取り専用ビューアを使い、未対応の新経路は内容を推測して表示せず、利用できない理由を案内します
- Office ファイルをブラウザーやリモート経由で扱うとき、実装されていない操作を対応済みとして案内しないようにしました。返せるデータの量を制限し、接続を閉じたときに処理中の要求と一時的なデータを確実に片付けます

### 新機能

- **Para Code を更新しても、走っているターミナルに繋ぎ直せる**ようになりました（設定 → ターミナル →「更新をまたいで繋ぎ直す」で有効化）。これまでは更新すると、それまでのターミナルは古い常駐に取り残されて見えるだけになっていました。SSH 先でも同じように動きます
- 上を有効にすると、**Para Code を閉じている間もコマンドが止まらずに走り切ります**。これまでは、閉じている間に一定量の出力が溜まった時点でプログラムが待ち状態になっていました。長く走ると古い出力から消えることがありますが、その場合は繋ぎ直したときに画面へその旨が出ます
- リモートエクスプローラーに「Para ホスト」ビューを追加しました。手元と SSH 先を同じツリーに並べ、スペースを展開するとエクスプローラーのように中のファイルやフォルダーを見られます。スペースの横には Workspaces ビューと同じ色の帯が付きます
- SSH 先のファイル・フォルダーを「このマシンへ保存」で手元に持ってくることができます。逆向きに、手元のファイルを「SSH 先へ送る」で送ることもできます。転送にはそのウィンドウの SSH 接続をそのまま使うので、追加の認証は不要です
- SSH 先から手元へ(またその逆へ)ファイルをドラッグ&ドロップしてコピーできるようになりました。複数選択したままのドラッグにも対応します
- SSH 先のフォルダーへ、手元から複数のファイルをまとめてアップロードできます
- **「Para ホスト」に、まだ接続していない SSH 先も並ぶ**ようになりました。`~/.ssh/config` に書いてあるホストが薄字で出て、展開すると中のファイルを見られます（初回だけ取得してよいか尋ねます）。接続していないホストは閲覧のみで、転送したいときは行を右クリックして「このホストに接続して開く」から繋いでください
- タイトルバーにポート一覧ウィジェットを追加しました。リッスン中のポートを検索・絞り込みしたり、対応するプロセスを終了（kill）したりできます。SSH 接続時は手元ではなく接続先でリッスンしているポートが表示されます
- 更新履歴を、左にバージョン一覧・右に内容を並べたモーダルで読めるようになりました（左下の歯車 →「更新履歴」）。まだ入れていない新しいバージョンの内容も「利用可能な更新」として先に読めるので、更新する前に何が変わるのかを確かめられます。読み込めないときは、いま入っているぶんだけが静かに出ます
- コマンドプリセットに「実行環境」の表示条件を付けられるようになりました。手元のマシンで作業しているときだけ出す、特定の SSH 接続先にいるときだけ出す、といった出し分けができます
- 使用量ダッシュボードで、コストとトークン数を切り替えて見られるようになりました。グラフも一覧も選んだほうの数字で並ぶので、コストが付かないモデルの消費量も分かります
- **AI コスト・GitHub API 残量・rtk の節約量を、1つのダイアログでまとめて見られる**ようになりました（コマンドパレットの「使用量ダッシュボードを開く」、または各ステータスバー項目から）。左のナビで3つを切り替えられ、「表示と取得元」タブでは実行パスやステータスバーの表示切り替えをその場で変更できます
- 左下の歯車 →「設定 (Para Code)」が、Para Code 独自の設定だけを機能ごとにまとめた専用ダイアログになりました。上の検索欄で横断的に探せ、通知設定・コマンドプリセット管理・ブラウザ共有・使用量ダッシュボードへはそれぞれの行のボタンから直接開けます
- 「新しいスペース」で最初に選んでおくエージェントを固定できるようになりました（設定 (Para Code) → スペース切替 →「既定のエージェント」）。空欄のままなら、これまでどおり前回選んだものを覚えて使います
- GitHub API のタブを開いている間の自動更新の間隔を選べるようになりました（手動のみ / 1分 / 5分 / 15分）。使用量ダッシュボードの「表示と取得元」から変更できます

### 改善

- Workspaces のスペース行を作り直しました。ブランチ名が行幅をいっぱいに使えるようになり、プルリクエスト・Issue 件数・未コミットの差分・メモの未完了件数はその下の専用の段にまとまります。これらを1つも持たない行はこれまでどおりの高さのままです
