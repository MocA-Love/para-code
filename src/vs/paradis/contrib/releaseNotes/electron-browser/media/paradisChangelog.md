# Para Code 更新履歴

Para Code が本家 VS Code に加えた変更の一覧です。新しいバージョンが上に来ます。

## 未リリース

### 修正

- `para browser page` が、開いた直後や移動した後のタブで URL と題名を空のまま返していたのを直しました。
- `para` のコマンドで、`--tab_id` と `--json` の `tab_id` を、タブを閉じる・選ぶ・プロファイルを切り替えるコマンドでも受けるようにしました。
- `para` のコマンドに相対パスで渡した保存先（`--file-path`・`--save-to` など）を、コマンドを打ったフォルダから解くようにしました。
- パフォーマンスの記録の保存先に `trace.json.gz` を渡すと `trace.json.json.gz` で保存されていたのを直しました。
- 内蔵ブラウザの道具の返事を直しました（古くなった要素を指したときの案内、ダウンロードが始まらなかったときの待ち時間、ページを離れる確認を断れないこと、画面に出ていないスペースのタブのプロファイルを切り替えられないこと）。

## paracode-195（2026-11-26）

### 新機能

- スペースの一覧で、リポジトリの中のスペースを「スペースのセクション」にまとめられるようになりました（リポジトリの行の右クリック「スペースのセクションを追加...」、スペースの行の右クリック「スペースのセクションへ移動」、ドラッグ）。見出しを押すと開閉し、消しても中のスペースは残ります。
- スペースのセクションの見出しの「+」で、そのセクションに入る新しいスペースを作れるようになりました（「新しいスペース」の詳細オプションの「セクション」でも選べます）。
- 「新しいスペース」の指示に GitHub の Issue・プルリクエストの URL を貼ると、題名がスペース名、番号がブランチ名に付くようになりました。
- 「新しいスペース」の指示にプルリクエストの URL を貼ると、元のブランチを「既存のブランチ」で開けるようになりました（fork から来たプルリクエストのスペースには、エージェントのフォルダの信頼を先に書きません。ほかの人のコードのためです）。
- ポートの一覧を、列の見出し（ポート・プロセス・公開・PID）を押して昇順・降順に並べ替えられるようになりました。「プロセスでまとめる」を押すと、同じプロセスのポートを 1 行に畳めます。選んだ並びは次に開いたときも同じです。
- Computer Use で、エージェントの操作を Esc を 2 回押してすぐに止め、通知やステータスバーから再開できるようになりました。
- Computer Use がほかのアプリを操作している間、ステータスバーに操作中の表示と止め方を出すようになりました。
- 内蔵ブラウザのパフォーマンスの記録（エージェントの `performance_start_trace`）で、保存するファイルにスクリプトの中身とソースマップを入れられるようになりました（`includeScriptContent`・`includeSourceMaps`。既定は入れません）。あとから Chrome DevTools で開いて、圧縮前のソースの位置で調べられます。

### 改善

- Claude Code・Codex の会話をセッション履歴・再開の帯・スマホから再開するとき、会話を始めたときに付けていたモデルの指定（`--model` など）と機能の切り替えの環境変数（`CLAUDE_CODE_EXPERIMENTAL_...` など、決まった名前のものだけ）を付け直すようになりました。`--dangerously-skip-permissions` を付けて始めた会話は、PC からの普通の再開でも確認なしで続きます（付けずに始めた会話は確認ありのままです。スマホからの再開は、どちらの会話も確認ありで始まります）。
- タイトルバーのポートの一覧で、すべてのネットワークから接続できるポートを文字の札「全公開」で示すようにしました（色の点・「*」の札・行の色をやめました。札にカーソルを置くと待ち受けのアドレスが出ます）。
- スペースの一覧のプロジェクトのセクションの見出しを、周りになじむ薄い帯にしました（検索の行と同じ薄い塗りと角丸で、テーマや自分で変えた色にも合います）。
- Computer Use で、操作の後に返す画面の構造を「前から変わった所だけ」にし、名前も操作も無い入れ物を一覧から外して、エージェントが読む量を減らしました。
- Computer Use で、操作の後に画面が落ち着くのを待ってから状態を返すようにしました（遅いアプリで古い状態を返しにくくなります）。
- Computer Use で、パスワード欄が入力を受けている間は、そのアプリへキーを送らないようにしました。
- Computer Use で、ブラウザ・リモートデスクトップ・取引アプリを既定で読み取りだけにし、設定で操作も許可できるようにしました。
- Device Hub の起動中に iOS のシミュレータへキー入力が届いていないかもしれないとき、タブの帯とエージェントへの結果で、そのことと試すこと（Device Hub を閉じる）を知らせるようにしました。
- パフォーマンスの分析結果（`performance_analyze_insight`）で、強制レイアウトを起こした関数を、ソースマップがあれば圧縮前のソースのファイルと行でも示すようになりました。
- サイドバーの「資料」で、資料のファイルを同じスペースの中の別の場所へ移しても、一覧が移動先を追うようになりました（中身が同じファイルが 1 つだけ見つかったとき）。
- 「資料」で、見つからない資料を 1 件ずつ並べず「見つからない資料 N 件」の 1 行に畳むようにしました。開くと中身を確かめて、まとめて外せます。7 日見つからないままの資料は自動で一覧から外れます（この版より前から見つからない資料は、更新した後に初めて確かめた日から 7 日を数えます）。
- 「新しいスペース」などの Codex のモデルの選択肢に、`gpt-6.2-sol`（既定）と `gpt-6.2-astra` を足しました（Codex からモデルの一覧を取れないときに出る一覧です）。

### 修正

- Code Mode で始めた Claude Code の会話を、セッション履歴・再開の帯・スマホから再開できるようになりました（これまでは「can't be resumed」と出て止まっていました）。
- iOS のシミュレータと Android の端末のタブに、映像が表示されない問題を直しました。
- iOS のシミュレータを止めて起動し直した後、映像が出ず「端末の取り込みが始まりません」のままになる問題を直しました（Para Code を開き直さなくても映像と操作が戻ります）。
- Para Code を終了した後、iOS のシミュレータの補助プロセスが CPU を使い続けたまま残ることがある問題を直しました。
- Android の端末のタブを開いた直後に映像の取り込みが落ち、画面が黒いままになる問題を直しました。
- Android 16 の端末を横向きにしたとき、エージェントに端末の向きと画面の大きさが縦のまま伝わり、2 本指の操作（ピンチ）の位置がずれる問題を直しました。
- Android のエミュレータで、エージェントがアプリを起動できない（`mobile_launch_app` が失敗する）ことがある問題を直しました。
- iOS のシミュレータや Android の端末のタブを表示したとき、内部でエラーが繰り返し起きることがある問題を直しました。内蔵ブラウザで表示サイズを固定したタブのページが落ちた後に、Para Code ごと終了することがある問題も直しました。
- 幅の狭いスペースの一覧で、スペースの行の PR・差分・メモの表示が途中で切れて読めなくなる問題を直しました（収まらない分は右の項目から隠します）。
- スマホから Claude Code の質問に答えた後、ペインとスマホの表示が「質問」のまま残ることがある問題を直しました（回答が Claude Code に渡った時点で外れます）。
- スマホや PC のカードで許可した後、許可したコマンドが動いている間ずっと、スマホの会話の上に「許可待ち」と出続ける問題を直しました。
- Claude Code の計画の確定（Would you like to proceed?）に、スマホの「許可」が効かず、カードだけが答えた表示になって計画が止まったままになることがある問題を直しました（スマホがつながっている間に出た確定で起きていました。子エージェントの計画の承認は、今までどおり PC で選びます）。
- Claude Code の計画の確定（Would you like to proceed?）で、スマホの「許可」や PC のカードの「はい」が、auto mode に入る選択肢（Claude Code 2.1.332 の 1 番「Yes, and use auto mode」）を選ぶことがある問題を直しました。画面の選択肢を読み、auto mode に入らない「Yes」を選びます。許可にあたる選択肢を読めないときは送らずに、PC のターミナルで選ぶよう知らせます。
- Claude Code のキーの割り当て（`keybindings.json`）を変えていると、質問のメニューが出ている間にチャット欄から送った文がメニューへ打ち込まれることがある問題と、チャット表示から質問に答えると「選択肢を確かめられませんでした」と断られる問題を直しました（Claude Code 2.1.329 以降。確定のキーを Enter から変えている場合、複数の質問の最後の送信は今までどおりターミナルで行います）。
- Claude Code の子エージェントの計画の承認が「No」だけの形（計画が長すぎて承認できないとき）で出ている間も、チャット欄から送った文を送らずに断るようにしました。会話を開き直した直後の確認（Resume this conversation?）は、取り消しのキーの割り当て（`keybindings.json`）を変えていても見分けます。
