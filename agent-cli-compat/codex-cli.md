# Codex CLI 準拠台帳

Para Code は Codex 0.155.1〜0.163.0 の範囲で実測・確認済みです。0.163.0 では、フラグ・サブコマンド・`model/list`・`hooks/list`（`currentHash` を含む）・`account/read` が 0.162.1 と同じで、hooks の schema、判定に使う TUI の文言、選択画面のファイルにも Para Code に当たる差分はありません。壊れる箇所は見つかっていません。新しい食い違いは 2 件で、どちらも 2026-10-16 にモデルを呼ぶ実測で確かめて直しました。cold resume でスレッドの権限が戻るようになり、Para Code の「bypass なし」の再開が bypass の権限で動いていた点（G11。普通の再開・分岐に確認ありの権限を明示した）と、Codex も OSC 7501 で状態を書くようになった点（G12。hook の届かないペインの補助に読むようにした）です。ほかに、作業中のモバイルからの発言が生成中の応答をその場で打ち切るようになりました（`instant_interrupt`、依存点「メッセージ送信」。Codex の既定に任せる）。以下は 0.162.1 の回の要約です。0.162.1 は 0.162.0 からの修正 2 件（非同期の質問の複数行での TUI のクラッシュ #51866、daemon の機能設定の互換確認をコマンド行で明示した features の上書きだけにする #52648）だけで、Para Code が依存するフラグ・hooks（currentHash も同じ）・`model/list`・state DB・rollout・TUI の文言に差分はありません。新しい食い違いはありません。以下は 0.162.0 の回の要約です。0.162.0 では、フラグ、hooks（schema・ハッシュとも差分なし）、hook の信頼の `currentHash`、`model/list`、state DB、Para Code が見る TUI の文言は変わっていません。rollout には新しい行（`additional_tools`、developer の役の base instructions）が加わり、`turn_context` からいくつかの項目が消えましたが、Para Code が読む項目は残っており、新しい行は無視されます。新しい食い違いは見つかっていません。0.162 のプレリリースで見張っていた変更（旧 G4）は安定版に入り、影響が無いことを確かめたので外しました。Windows のペインが共有 daemon に相乗りする点（G1）は引き続き残ります。
